# Local demo

Bootstrap a disposable product-repo sandbox to exercise Floors + the specialist catalog.

```bash
npm install
npm run demo:local
```

See [docs/guide/Demo.md](../docs/guide/Demo.md) and [playbook.md](playbook.md).

`demo/workspace/` is gitignored (generated). Specs live under `.specs/features/demo-*` (also git-only, not on npm).
