# Layer registry

`.specs/project/PROJECT.md` is created on first install and **not** overwritten on later installs (unless `--sync-registry`).

## Sections

- **Stack** — frameworks and layout (helps specialist selection)  
- **Layer registry** — Floor id → skill file → globs  
- **Test / lint commands** — discovered before each task  

`--sync-registry` rewrites **only** the Layer registry table from package defaults.
