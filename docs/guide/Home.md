# Home

**Seatbelt keeps you safe. Lanes map the stack — specialists enter only when called.**

Agents fail when they mix lanes in one turn: UI, API, dbt, and training in the same task `Files` and the same context.

This package is the **Full Stack Floor Map** companion to [Spec Seatbelt](https://github.com/luizssantiago92/spec-seatbelt):

1. **Lanes (Execute path layers)** — five lean `*-engineering.md` manuals + layer registry + `validate-layers` (docs may still say “Floors”)  
2. **Specialist catalog** — ~67 Agent Skills (`SKILL.md` + `references/`) adapted from [claude-skills](https://github.com/Jeffallan/claude-skills)  
3. **Load policy** — one Lane + at most one specialist + ≤2 craft references per Execute turn  
4. **Desks (planned 0.5.0)** — specialist rooms + memory under `.specs/desks/` (INDEX, preferred, handoff) — not shipped on npm yet  

They are **two packages**. Re-installing Seatbelt does not delete Floor Map skills, catalog, the layer gate script, or (when present) `.specs/desks/`.
