# Home

**Seatbelt keeps you safe. Floors map the stack — specialists enter only when called.**

Agents fail when they mix floors in one turn: UI, API, dbt, and training in the same task list and the same context.

This package is the **Full Stack Floor Map** companion to [Spec Seatbelt](https://github.com/luizssantiago92/spec-seatbelt):

1. **Floors (legacy Execute)** — five lean `*-engineering.md` manuals + layer registry + routing gate  
2. **Specialist catalog** — ~67 Agent Skills (`SKILL.md` + `references/`) adapted from [claude-skills](https://github.com/Jeffallan/claude-skills)  
3. **Load policy** — one Floor + at most one specialist + ≤2 references per Execute turn  

They are **two packages**. Re-installing Seatbelt does not delete Floors skills.
