# How it works

With both packages installed:

1. **Specify / Tasks** — Seatbelt phases; write `spec.md` + `tasks.md` with one **Lane** per task `Files`  
2. **validate-layers** — Floor Map gate before Execute  
3. **Execute /loop** — Seatbelt `loop-plan` + one Lane manual + optional specialist (when Desks ship: INDEX → DESK → preferred)  
4. **Verify** — Seatbelt only (no Lane manuals, no catalog, no desk staffing)  
5. **Archive** — Seatbelt archive  

Parallel waves (`loop-plan`): tasks in the same wave must not share files (Seatbelt) and still one Lane each (Floor Map).

See Seatbelt [Companion: Full Stack Floor Map](https://github.com/luizssantiago92/spec-seatbelt/blob/cursor/companion-desks-v3-docs-29db/docs/guide/Companion-fullstack-floor-map.md) ([PR #80](https://github.com/luizssantiago92/spec-seatbelt/pull/80)) and our [Companion-spec-seatbelt.md](Companion-spec-seatbelt.md).
