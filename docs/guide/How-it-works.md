# How it works

With both packages installed:

1. **Specify / Tasks** — Seatbelt phases; write `spec.md` + `tasks.md` with one Floor per task `Files`  
2. **validate-layers** — Fullstack gate before Execute  
3. **Execute /loop** — Seatbelt `loop-plan` + Floors manual + optional specialist  
4. **Verify** — Seatbelt only  
5. **Archive** — Seatbelt archive  

Parallel waves (`loop-plan`): tasks in the same wave must not share files (Seatbelt) and still one Floor each (Fullstack).

See Seatbelt [Companion: Agentic Fullstack](https://github.com/luizssantiago92/spec-seatbelt/blob/main/docs/guide/Companion-agentic-fullstack.md) and our [Companion-spec-seatbelt.md](Companion-spec-seatbelt.md).
