# Wiki source

Markdown pages for the GitHub Wiki of `@luizsantiago/agentic-fullstack`.

GitHub Wiki is not enabled yet (`agentic-fullstack.wiki.git` does not exist). After enabling **Settings → Features → Wikis**:

1. Create the first page in the GitHub UI (any title) so `https://github.com/luizssantiago92/agentic-fullstack.wiki.git` exists.
2. Clone the wiki repo and copy these files (keep `_Sidebar.md` at the root).
3. Commit and push.

Page slug = filename without `.md`. `_Sidebar.md` is the left navigation.

Do not add this folder to the npm package (`package.json` `files` already omits it).
